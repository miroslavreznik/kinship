# Development disclosure

Kinship: Overclock is designed and directed by **daitosem**. AI assistance (Codex) was used for programming, tests, planning, story text, functional sound synthesis code, prototype UI/rendering code and the temporary Lucky draft. The supplied Ansimuz artwork and music, including the menu track **One Tree Forest**, are licensed external assets, not generated by this project. The previous procedural menu loop was replaced and is not included in the current build.

The active Lucky asset, `game/assets/characters/lucky/heat-states.png`, is a new **AI-generated pixel-art development draft**. An image-generation tool redrew the previous AI draft in a style informed by the game actors; offline normalisation produced a 144×48 sheet of three native 48×48 frames, a 16-colour palette and binary alpha. Runtime code displays these frames directly, without resizing the old illustration into pixel art. The generated intermediate is `prototype-only/lucky-pixel-redraw-generated.png`; the older `prototype-only/lucky-heat-states-ai-draft.png` is preserved. [Detailed provenance](lucky-pixel-art.md).

Both Lucky drafts are **not eligible jam artwork**. Redrawing with AI, palette reduction or resizing does not make artwork human-created. Replace the active sheet with independently human-created art before submission, then update this disclosure to match the final files. MSI retains its rights in Lucky; this is not an official or MSI-approved product. Official reference pictures are not distributed in the build.

The jam requires assets, tools and AI use to be disclosed in the itch.io game description and prohibits AI-created graphics. The final submission description must match the final files. Review any prototype UI or visual rendering code against the full rules rather than assuming that replacing Lucky alone establishes compliance.

Sources: [jam overview](https://itch.io/jam/msi-czsk-gamejam-2026), [full rules](https://docs.google.com/document/d/1k5kYpHmLTHpeyZVjVjejVYxt9JIdo0xC/edit), [Lucky appendix](https://docs.google.com/document/d/1NseyD8P8SfDWeuOhQbHCJTdG6y1Nuwca/edit).
