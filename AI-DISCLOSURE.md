# Development disclosure

Kinship: Overclock is designed and directed by **daitosem**. AI assistance (Codex) was used for programming, tests, planning, story text, functional sound synthesis code, prototype UI/rendering code and earlier Lucky development drafts. The supplied Ansimuz artwork and music, including the menu track **One Tree Forest**, are licensed external assets, not generated by this project. The previous procedural menu loop was replaced and is not included in the current build.

The active Lucky asset, `game/assets/characters/lucky/heat-states.png`, is the replacement PNG supplied by **daitosem** on 10 November, described by the owner as manually redrawn. It replaces the AI development sheet; installation preserves the supplied file rather than regenerating or pixelating it. Artwork credit: daitosem. Lucky character: MSI. This records the owner's stated authorship without making an additional claim about independent creation. [Detailed provenance and development history](lucky-pixel-art.md).

Earlier AI Lucky drafts and their generation record are retained privately as archival development history, not current game artwork. Those drafts were not eligible final jam art; their replacement does not erase the project's earlier AI use. MSI retains its rights in Lucky; this is not an official or MSI-approved product. Official reference pictures are not distributed in the build.

The jam requires assets, tools and AI use to be disclosed in the itch.io game description and prohibits AI-created graphics. The final submission description must match the final files and retain truthful development history. Review the owner's final artwork provenance and any prototype UI or visual rendering code against the full rules; replacing Lucky alone does not establish overall compliance.
